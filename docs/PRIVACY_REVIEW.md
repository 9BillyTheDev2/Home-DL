## Limite du nettoyage

La réécriture de main retire l’ancienne version de l’historique principal. GitHub peut conserver des objets non référencés, des caches ou des références associées aux exécutions Actions. Ce contrôle n’atteste pas leur suppression physique. Une purge définitive de références côté GitHub peut nécessiter l’assistance GitHub.

Le compte propriétaire du dépôt et son profil GitHub restent visibles lorsque le dépôt est public. Le passage en public ne doit pas être présenté comme une anonymisation du compte.

- Aucune clé de signature permanente ou donnée d’authentification créée lors de ce contrôle.
- Aucun changement de visibilité exécuté par la connexion GitHub disponible, qui ne propose pas cette opération.
- Le propriétaire a validé le passage en public ; l’opération reste à effectuer dans les paramètres du dépôt.
